ℹ️ How Catch-Up Works

  1. Before each player's turn, check if they're trailing the leader
  2. If trailing by ≥3 VP, give bonus resources (+2 per VP behind, max 6)
  3. If trailing by ≥6 VP, also give +1 VP bonus
  4. Bonus is added as triangles to budget cards in hand
  5. AI also receives catch-up bonuses (fairness)

🔧 Troubleshooting

If catch-up doesn't seem to be working:

  • Check browser console for JavaScript errors
  • Add console.log() in applyCatchUpBonus() to verify it's called
  • Check state.js values are correctly set (catchUpThreshold = 3)
  • Verify budget cards exist in hand to receive triangles
